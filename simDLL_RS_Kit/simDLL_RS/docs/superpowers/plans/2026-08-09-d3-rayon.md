> **前提：** 先读 `docs/d3_rayon_技术参考.md`（桌面版旧 d3 线提炼）；本计划在其基础上按 v1 结构重新实现，**不照抄旧代码**。v1 串行路径必须始终全绿（537 测试），d3 默认关闭（feature 门控）。

**目标：** 在 v1（my_Project\simDLL_RS_Kit_v1\simDLL_RS）上实现 d3_rayon：多星（多活动区域）时把各世界网格物理分给物理核心并行，单星/单区域走原版串行路径（行为零变化）；所有 d3 专属代码收进 `src/d3_rayon/`，用 Cargo feature `d3-rayon` 门控——默认编译即当前 v1 稳定版，移走 `src/d3_rayon/` + 关闭 feature 也能编译。

**架构：** 三段式并行：阶段 A（网格物理：温度内联→区域局部 CopyFrom→气体→CopyFrom→液体→CopyFrom→病菌→太空真空→辐射，每区域组 1 个 rayon job）→ 合并 A 事件 → 阶段 B（组件串行，按 ★4 注册顺序）→ 阶段 C（PostProcess+病菌生长并行）→ 合并 C 事件。正确性四支柱：D1 门控（区域数>1）、T4 每区域独立持久 RNG、T3 每区域独立事件缓冲（线程局部 sink）、T2 区域局部 CopyFrom（halo）。线程池 = rayon，线程数 = 物理核 − 1（reserve）。区域分组用 LPT 面积装箱。

**技术栈：** Rust（cdylib）、rayon（optional feature）、Windows API（GetLogicalProcessorInformation 数物理核，v1 已含 Win32_System_SystemInformation feature）、线程局部 sink/rng 路由（`thread_local!` + 裸指针）。

**目录结构（最终形态）：**

```text
├─ d3_rayon/                  ← feature "d3-rayon" 门控（移走/关闭 = 稳定版）
```

```rust
use std::sync::OnceLock;

pub const RESERVE_CORES: usize = 1;

pub fn physical_cores() -> usize {
    use windows::Win32::System::SystemInformation::{
        GetLogicalProcessorInformation, RelationProcessorCore, SYSTEM_LOGICAL_PROCESSOR_INFORMATION,
    };
    unsafe {
        let mut needed: u32 = 0;
        if GetLogicalProcessorInformation(None, &mut needed).is_err() || needed == 0 {
            return fallback_parallelism();
        }
        let count = (needed as usize) / std::mem::size_of::<SYSTEM_LOGICAL_PROCESSOR_INFORMATION>();
        if count == 0 {
            return fallback_parallelism();
        }
        let mut buf = vec![SYSTEM_LOGICAL_PROCESSOR_INFORMATION::default(); count];
        if GetLogicalProcessorInformation(Some(buf.as_mut_ptr()), &mut needed).is_err() {
            return fallback_parallelism();
        }
        let cores = buf
            .iter()
            .filter(|info| info.Relationship == RelationProcessorCore)
            .count();
        if cores == 0 { fallback_parallelism() } else { cores }
    }
}

fn fallback_parallelism() -> usize {
    std::thread::available_parallelism().map(|n| n.get()).unwrap_or(4)
}

pub fn should_parallelize(region_count: usize) -> bool {
    region_count > 1
}

static G_RAYON_POOL: OnceLock<rayon::ThreadPool> = OnceLock::new();

pub fn pool() -> &'static rayon::ThreadPool {
    G_RAYON_POOL.get_or_init(|| {
        let threads = physical_cores().saturating_sub(RESERVE_CORES).max(1);
        rayon::ThreadPoolBuilder::new()
            .thread_name(|i| format!("simdll-d3-{i}"))
            .num_threads(threads)
            .build()
            .expect("d3: rayon ThreadPool build failed")
    })
}
```

```rust
use crate::d1_activity::RegionBounds;

pub fn bin_pack_region_groups(bounds: &[RegionBounds], group_count: usize) -> Vec<Vec<usize>> {
    let n = bounds.len();
    if n == 0 { return Vec::new(); }
    let groups = group_count.min(n);
    let mut order: Vec<usize> = (0..n).collect();
    order.sort_unstable_by(|&a, &b| {
        bounds[b].cell_count().cmp(&bounds[a].cell_count()).then(a.cmp(&b))
    });
    let mut loads = vec![0u64; groups];
    let mut out: Vec<Vec<usize>> = (0..groups).map(|_| Vec::new()).collect();
    for &i in &order {
        let g = loads.iter().enumerate().min_by_key(|(_, &l)| l).map(|(gi, _)| gi).unwrap();
        loads[g] += bounds[i].cell_count();
        out[g].push(i);
    }
    out
}
```

```rust
/// 并行路径：只复制区域矩形 + halo 边界 1 格到 cells 快照（T2）。
/// halo 落在区域间真空 buffer，跨区域读安全；边界 clamp 到网格边缘。
pub fn copy_updated_cells_to_cells_region(sim_data: &SimData, bounds: &RegionBounds) {
    if sim_data.cells.ptr.is_null() || sim_data.updated_cells.ptr.is_null() {
        return;
    }
    let w = sim_data.width as usize;
    let h = sim_data.height as usize;
    let halo = 1usize;
    let min_x = bounds.min_x.saturating_sub(halo);
    let min_y = bounds.min_y.saturating_sub(halo);
    let max_x = bounds.max_x.saturating_add(halo).min(w);
    let max_y = bounds.max_y.saturating_add(halo).min(h);
    if min_x >= max_x || min_y >= max_y {
        return;
    }
    let cells = unsafe { &mut *sim_data.cells.ptr };
    let upd = unsafe { &*sim_data.updated_cells.ptr };
    // 逐字段复制（与 copy_updated_cells_to_cells 相同的字段集）：
    // element_idx / temperature / mass / properties / insulation /
    // disease_idx / disease_count / disease_infestation_tick_count /
    // disease_growth_accumulated_error / radiation
    for row in min_y..max_y {
        for col in min_x..max_x {
            let i = row * w + col;
            cells.element_idx.set(i, upd.element_idx.get(i));
            cells.temperature.set(i, upd.temperature.get(i));
            cells.mass.set(i, upd.mass.get(i));
            cells.properties.set(i, upd.properties.get(i));
            cells.insulation.set(i, upd.insulation.get(i));
            cells.disease_idx.set(i, upd.disease_idx.get(i));
            cells.disease_count.set(i, upd.disease_count.get(i));
            cells.disease_infestation_tick_count.set(i, upd.disease_infestation_tick_count.get(i));
            cells.disease_growth_accumulated_error.set(i, upd.disease_growth_accumulated_error.get(i));
            cells.radiation.set(i, upd.radiation.get(i));
        }
    }
}
```

> 字段集以 `copy_updated_cells_to_cells` 现有实现为准（复制它复制的全部字段）。

```rust
pub(crate) fn with_region_sink<T>(sink: *mut RegionEvents, f: impl FnOnce() -> T) -> T {
    REGION_EVENTS_SINK.with(|s| {
        let prev = s.get();
        s.set(Some(sink));
        let result = f();
        s.set(prev);
        result

    REGION_EVENTS_SINK.with(|s| s.get())
```
